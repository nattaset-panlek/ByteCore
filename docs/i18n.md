# Localization (`app/src/i18n`)

Every user-visible string goes through `t()`. English is the only language shipped; adding one is a dictionary file.

## Using it

```tsx
import { useT, fmt } from "../i18n";
function View() {
  const t = useT();                       // re-renders on language change
  return <span>{t("wallet.totalBalance")}</span>;
}
```

- `t(key, vars?)` — looks up the key, fills `{placeholders}` from `vars`. Numbers in vars are formatted for the locale. Unknown keys return the key itself (so old saves with plain-text labels still render).
- `useT()` — the same `t`, as a hook; call it in a component so it updates when the locale changes. Outside React, import `t` directly.
- `fmt` — locale-aware formatting: `number`, `credits` (`₵ 1,234`), `signedCredits`, `date`, `time`, `dateTime`, `shortDate`.
- Plurals: define `key_one` and `key_other`, call `t("key", { count })`.
- `Msg` / `msg(key, vars)` / `tm(msg)` — a translatable message passed as data. Store `Result.error` and `Txn.label` are message keys, shown with `tm()` / `t(label, vars)`.

## Dictionaries

`src/i18n/en/` is split by area and merged in `en/index.ts`: `game`, `shell`, `apps`, `terminal`, `chimera`, `exchange`, `contracts`, `taskmgr`, `modules`. Keys are flat and dotted (`"wallet.totalBalance"`).

To add a language: add `xx/index.ts` with the same keys, register it in `LOCALES` in `src/i18n/index.ts` (label + `Intl` locale). Missing keys fall back to English. The locale is chosen in Settings → Home → Language and saved in `localStorage`.

## What stays untranslated (data, not text)

Product / part / brand / model names, spec strings, file names, the player name and email, target org names and addresses, `core://` URLs, and terminal command names (`scan`, `pull`, …) — command *names* are the game's syntax; their help text is translated.
